これは、形の基本要素の例に色を追加することで拡張しています。
<a href="/reference/p5/background" target="_blank">background()</a>
はキャンバスを1色で塗りつぶし、
<a href="/reference/p5/stroke" target="_blank">stroke()</a>
は線を描くための色を設定し、
<a href="/reference/p5/fill" target="_blank">fill()</a>
は形の内側の色を設定します。
<a href="/reference/p5/noFill" target="_blank">noStroke()</a> と
<a href="/reference/p5/noFill" target="_blank">noFill()</a>
は、それぞれ線の色と内側の色をオフにします。

色は多くの異なる方法で表現できます。この例ではいくつかのオプションを示しています。
