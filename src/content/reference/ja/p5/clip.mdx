description: >
  <p>後続のすべての描画をマスクする形状を定義します。</p>

  <p>最初のパラメータ<code>callback</code>は、マスクを定義する関数です。
  <code>callback</code>内で描画されたすべての形状がマスク形状に追加されます。
  マスクは、<code>clip()</code>が呼び出された後に描画されるものすべてに適用されます。</p>

  <p>2番目のパラメータ<code>options</code>はオプションです。
  <code>beginClip({ invert: true })</code>のように<code>invert</code>プロパティを持つオブジェクトを渡すと、
  マスキングモードを設定できます。<code>{ invert: true }</code>はマスクを反転させ、
  マスクされた形状に穴を作成します。<code>invert</code>はデフォルトで<code>false</code>です。</p>

  <p>マスクは<a href="/reference/p5/push/">push()</a>関数と
  <a href="/reference/p5/pop/">pop()</a>関数の間に含めることができます。
  これにより、マスクされていない形状をマスクされた形状の後に描画することができます。</p>

  <p>マスクは<a href="/reference/p5/beginClip/">beginClip()</a>と
  <a href="/reference/p5/endClip/">endClip()</a>を使っても定義できます。</p>
